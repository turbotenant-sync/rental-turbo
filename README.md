# RentCast Rental Listing Page

RentCast is a TanStack Start marketing site for landlords and property teams that need to advertise rental properties, publish listings broadly, and organize renter leads. The home page is a polished landing page inspired by a rental-property advertising reference, with responsive sections for distribution, workflow, and listing benefits.

## Key Technologies

- TanStack Start with file-based routing
- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Lucide React icons
- Netlify deployment configuration

## Run Locally

Install dependencies, then start the local development server:

```bash
npm install
npm run dev
```

For Netlify feature emulation, use Netlify Dev:

```bash
netlify dev
```

The Vite app runs on port `3000` by default. Netlify Dev proxies the app through port `8888` based on `netlify.toml`.
